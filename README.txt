
# Port Number Explainer 

A beginner-friendly Python project that explains common port numbers and their associated network services.

## Features
- Identifies common port numbers.
- Displays the associated service.
- Checks whether a port number is within the valid range.
- Handles invalid input.

## Requirements
- Python 3
- No extra libraries required.

## How to Run

1. Download or clone this repository.
2. Open the project folder in your terminal.
3. Run:

   ```bash
   python port_explainer.py
   ```

4. Enter a port number when prompted.

## Example

```text
Enter a port number: 443

Port Found!
Port Number: 443
Service: HTTPS - Secure Web Traffic
```
